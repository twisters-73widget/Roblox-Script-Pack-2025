## FAQ

### What is XCutors?

XCutors is a curated collection of popular Roblox script executor tools for Windows. It bundles several well-known executors—Volt, Synapse Z, Potassium, Wave—and a universal loader (xcutorsLoader) into a single, easy-to-manage desktop application.

### Is XCutors free to use?

XCutors itself is a free management and loading interface. However, some of the bundled executors may have their own licensing or subscription requirements. Please check each executor's official website for pricing details.

### Which versions of Windows are supported?

XCutors supports Windows 10 (version 1903 and later) and Windows 11 (64-bit). Both Home and Pro editions are compatible. Windows 7 and 8 are not officially supported.

### How do I update the bundled executors?

XCutors includes a built-in auto-update mechanism. Navigate to Settings → Updates and click 'Check for Updates.' The tool will automatically download and apply the latest stable versions of all installed executors.

### Can I add my own scripts to the library?

Yes. Navigate to the Script Library tab and click 'Import Script.' You can add .lua or .txt files individually or import an entire folder of scripts. Scripts are organized into user-defined categories for easy management.

### My anticomponent is flagging XCutors. Is it safe?

Some anticomponent engines may flag script execution tools due to their injection and memory-manipulation mechanisms. We recommend adding the XCutors installation folder to your anticomponent exclusion list. Always download XCutors only from this official GitHub repository to avoid tampered copies.

### Does XCutors work with the Microsoft Store version of Roblox?

XCutors is primarily designed for the standard Roblox desktop client. Compatibility with the Microsoft Store version is not guaranteed, and you may experience issues. We recommend using the standard client from roblox.com for the best experience.

### How do I switch between different executors?

Use the executor selector dropdown in the main application window. Choose your desired executor (Volt, Synapse Z, Potassium, or Wave), and xcutorsLoader will automatically configure the environment and prepare it for script execution.

### Where are logs and crash reports stored?

Logs and crash reports are saved in the 'Logs' subfolder within your XCutors installation directory (e.g., C:\XCutors\Logs). You can also access them directly from the application via Help → Open Log Directory.

### How can I report bugs or request features?

Please open an Issue on this GitHub repository. Provide a clear description of the bug or feature request, your Windows version, the executor you were using, and any relevant log files. We aim to respond to new issues within 48 hours.

### Is there a Discord or community forum for XCutors?

Yes, community support and discussion are available through the links listed in the README. Join our Discord server for real-time help, script sharing, and update announcements.
